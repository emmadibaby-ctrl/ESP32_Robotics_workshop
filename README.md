# ESP32 Robotics Workshop



\## About

This repository contains six robotics projects developed during a two-day Embedded Enhancement Workshop conducted by Robomonk Technologies using ESP32.



\## Projects



\### 1. Four-Direction Movement Robot

Developed a robot capable of moving forward, backward, left, and right.



\### 2. Obstacle Detector Robot

Built a robot that detects obstacles in its path.



\### 3. Object Following Robot

Developed a robot that follows an object based on sensor input.



\### 4. Clap-Controlled Robot

Implemented robot movement control using clap-based sound detection.



\### 5. Black Line Follower Robot

Developed a robot that follows a black line using sensors.



\### 6. Edge Detector Robot

Built a robot that detects edges to help prevent it from moving off a surface.



\## Technologies Used

\- ESP32

\- Arduino IDE

\- Embedded C/C++

\- Sensors and motor control

\- Robotics



\## Learning Outcomes

\- Hands-on experience with ESP32 programming.
